# Parkside GA Hiring Ads

Recruitment-marketing creative for The Parkside Group's Georgia openings — one branded set
for LinkedIn and Instagram, built in the company identity (navy `#16233F`, gold `#C9A44C`,
cream `#F1EDE2`) with the real logo and a QR code that goes to the application form.

## What's here

`graphics/` — six 1080×1080 ads, each in two formats:

| Role set | PNG (LinkedIn / hi-res) | JPEG (Instagram) |
|---|---|---|
| CNAs & Caregivers | `graphics/cna.png` | `graphics/cna.jpg` |
| RNs & LPNs | `graphics/rn-lpn.png` | `graphics/rn-lpn.jpg` |
| Med Techs | `graphics/medtech.png` | `graphics/medtech.jpg` |
| Rehab & Therapy | `graphics/rehab.png` | `graphics/rehab.jpg` |
| Nurse Leaders | `graphics/nurse-leaders.png` | `graphics/nurse-leaders.jpg` |
| Office & Admin Team | `graphics/office-admin.png` | `graphics/office-admin.jpg` |

`graphics/parkside-logo.png`, `graphics/qr.svg` — brand assets used in the graphics.

`captions.md` — LinkedIn (long) and Instagram (short) caption for every ad.

## Apply funnel

- **Form:** https://form.jotform.com/262605908046055 → emails every lead to blimi@parksidegrp.com
- Every graphic carries a **QR code** to that form, and each caption links/points to it.
- Set the **Instagram bio link** to the form URL so "link in bio" works.

## Auto-posting note

If this repository is **public**, each graphic has a public raw URL, e.g.
`https://raw.githubusercontent.com/blimikraus-ux/marketing/main/ga-hiring-ads/graphics/cna.jpg`
— which Instagram and LinkedIn can fetch. That is the one piece needed to publish these
hands-off through Composio. See the Auto-Posting Runbook for the full flow.
